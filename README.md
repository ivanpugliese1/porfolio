# Portfolio — Ivan Pugliese

Portfolio personal como desarrollador Full-Stack en formación.

## 🚀 Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Framer Motion
- React Icons

## 📁 Estructura
```
src/
├── components/
│   ├── layout/        # Header, Footer, BottomNav
│   └── sections/      # Hero, Experience, Projects, About, Contact
├── context/           # ThemeContext, ThemeProvider
├── data/              # projects.ts, experience.ts, navigation.ts, tags.ts
├── hooks/             # useTheme.ts
└── types/             # index.ts
```

## 🛠️ Instalación
```bash
npm install
npm run dev
```
